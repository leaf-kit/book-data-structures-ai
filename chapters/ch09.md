# 9장 트라이, 토크나이저, 접두사 캐시

1960년의 논문 하나는 문자열을 저장하는 새 방법의 이름을 retrieval 의 가운데에서 따 왔다.

## 절

- **9.1** 트라이와 최장 일치. 탐색 비용이 문자열 길이에만 달렸다. 토큰화가 dict 방법보다 여섯 배
- **9.2** 바이트 쌍 부호화. 병합 순서가 어휘이자 규칙이다. 최장 일치와 단어의 8 퍼센트가 다르게 나뉜다
- **9.3** 라디스 트리 위의 KV 캐시. 접두사 공유로 계산이 7 분의 1. 축출은 잎만
- **9.4** 제약 디코딩. 트라이 위의 오토마톤. 허용 집합의 비용이 어휘 크기와 무관하다

## 연습문제

- 문제 9.1 (기초) 어휘 항목 50,000 개, 평균 길이 6 바이트의 트라이 노드 수 상한을 앞의 정의 로 구하라. 노드마다 자식 배열 256 칸을 두면 메모리가 얼마이고, 간선당 24 바이트의 해시로 두면 얼마인가.
- 문제 9.2 (기초) 단어 표의 토큰 수 합이 $10^7$ 이고 병합이 $3 10^4$ 개일 때, 매 단계 전부 세는 학습과 색인을 둔 학습의 비용을 앞의 정의 로 견줘라. 병합당 평균 단어 수를 200 으로 두라.
- 문제 9.3 (기초) 시스템 프롬프트 2,000 토큰을 나누는 사용자 1,000 명이 각자 200 토큰씩 열 턴을 이어 갈 때, 캐시 없이 계산하는 토큰 수와 앞의 정의 의 서로 다른 접두사 총 길이를 구하라.
- 문제 9.4 (기초) 상태 2,000 개, 어휘 128,000 개의 마스크 표는 몇 MB 인가. 앞의 정의 로 구하고, 디코딩 한 단계에 읽는 비트 수를 적어라.
- 문제 9.5 (응용) `dsai.trie.Trie` 의 자식 표현을 뿌리의 자식만 256 칸 배열로 바꿔라. 실험 9.1 의 토큰화 시간이 얼마나 바뀌는지 재고, 어느 층까지 배열로 두는 것이 나은지 논하라.
- 문제 9.6 (응용) `dsai.bpe.encode_by_merges` 를 힙으로 바꿔라. 이웃 쌍의 순위를 힙에 넣고 최소를 꺼내 합친 뒤 새로 생긴 쌍만 넣는다. 긴 단어에서 시간이 얼마나 주는지 재라.
- 문제 9.7 (응용) `dsai.radix.RadixCache` 에 참조 수를 더하라. 요청이 쓰는 동안 그 경로의 노드는 떼지 않고, 요청이 끝나면 참조를 푼다. 실험 9.3 을 요청 둘씩 겹쳐 돌려 참조 수 없이는 무엇이 잘못되는지 시험으로 보여라.
- 문제 9.8 (응용) `dsai.constrained.number_dfa` 를 따옴표로 감싼 문자열 형식 (`"` 뒤에 따옴표 아닌 바이트들, 다시 `"`) 으로 바꾸고, 상태마다 허용 집합의 크기와 트라이가 지나는 노드 수를 재라. 숫자 형식과 왜 다른가.
- 문제 9.9 (탐구) 병합 순서 부호화가 최장 일치보다 학습 때의 분포에 맞는 이유를 앞의 정의 의 불변식으로 설명하라. 최장 일치로 학습한 모델에 병합 순서로 넣으면 무엇이 달라지는가.
- 문제 9.10 (탐구) KV 캐시의 축출이 잎에 한정되는 것과 5.4절 의 블록 테이블에서 블록이 참조 수를 갖는 것을 견줘라. 두 구조를 하나로 합치면 무엇이 노드이고 무엇이 블록인가.

## 더 읽을 것

- Trie Memory (1960). 트라이의 원전. 열 쪽이고, 접근 시간과 갱신과 길이가 다른 키에 대한 장점이 그대로 적혀 있다. (9.1절)
- PATRICIA: Practical Algorithm To Retrieve Information Coded in Alphanumeric (1968). 경로 압축 트라이의 원전. 라디스 트리의 불변식과 비트 단위의 갈림이 여기서 나왔다. (9.3절)
- Neural Machine Translation of Rare Words with Subword Units (2016). 바이트 쌍 부호화를 어휘 만들기에 가져온 논문. 단어 안에서만 병합하는 규칙이 이 장의 구현이다. (9.2절)
- SGLang: Efficient Execution of Structured Language Model Programs (2024). 라디스 트리 위의 KV 캐시와 압축 오토마톤. 9.3 절과 9.4 절의 현장이다. (9.3, 9.4절)
- Efficient Guided Generation for Large Language Models (2023). 정규식을 오토마톤으로 바꿔 어휘의 허용 집합을 미리 색인하는 방법. 9.4 절의 출발이다. (9.4절)
- Efficient String Matching: An Aid to Bibliographic Search (1975). 여러 패턴을 한 오토마톤에 넣는 원전. 9.4 절이 뒤집은 방향의 원래 방향이다. (9.4절)
