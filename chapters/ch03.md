# 3장 희소 행렬과 저정밀 표현

2021년 가속기 제조사의 논문은 행렬 곱 장치에 네 칸 중 두 칸이라는 규칙을 직접 읽는 회로를 넣어 밀집의 두 배 처리량을 냈다고 적었다.

## 절

- **3.1** COO, CSR, CSC 를 정의하고, CSR 이 이기는 밀도가 50 퍼센트가 아니라 2 퍼센트인 이유를 잰다
- **3.2** 블록 희소와 2:4. 규칙이 인덱스와 라인을 아끼고, 2:4 의 시간 이득은 장치가 있어야 한다
- **3.3** 블록 양자화. 스케일을 블록마다 두면 이상값의 영향이 갇혀 오차가 500 배 준다
- **3.4** 전문가 혼합. 배정은 희소 행렬이고, 읽는 전문가 수의 기대값이 밀도를 정한다

## 연습문제

- 문제 3.1 (기초) $5 5$ 행렬에서 0 이 아닌 원소가 $(0,2)=1$, $(2,0)=4$, $(2,4)=2$, $(4,1)=3$ 일 때 CSR 세 배열과 CSC 세 배열을 각각 적어라.
- 문제 3.2 (기초) float16 원소와 4바이트 인덱스에서 정리 3.1 의 이동량 문턱을 구하고, 명제 3.2 처럼 라인 64 를 넣으면 얼마가 되는지 구하라.
- 문제 3.3 (기초) $1024 1024$ float16 행렬을 2:4 로 담을 때의 바이트, 블록 16 BSR 로 밀도 50 퍼센트를 담을 때의 바이트, CSR 로 담을 때의 바이트를 구하라.
- 문제 3.4 (기초) 값이 $[-0.05, 0.05]$ 에 고르게 있고 하나가 $2.0$ 인 원소 4,096 개를 8비트로 양자화할 때, 텐서 하나 스케일과 블록 64 스케일 각각에서 이상값이 아닌 원소의 오차 상한을 구하라.
- 문제 3.5 (응용) `dsai.sparse` 에 CSR 과 CSR 의 곱 (행렬 행렬 곱) 을 구현하고, 밀도 1 퍼센트에서 밀집 곱과 시간을 비교하라. 결과의 밀도가 얼마가 되는지도 재라.
- 문제 3.6 (응용) `dsai.structured.dense_to_bsr` 의 블록 크기를 8, 16, 32, 64 로 바꿔 실험 3.2 의 블록 희소 행렬을 다시 재고, 명제 3.3 의 인덱스 바이트와 라인 수를 한 표에 놓아라.
- 문제 3.7 (응용) `dsai.quant.quantize` 에 스케일 자체를 8비트로 양자화하는 이중 양자화를 더하고, 블록 64 에서 원소당 바이트가 얼마나 주는지와 오차가 얼마나 느는지 재라.
- 문제 3.8 (응용) `dsai.moe.moe_forward` 에 전문가마다 받을 수 있는 토큰 수의 상한 (용량 인자) 을 더하고, 상한을 넘은 토큰을 버릴 때 배치 256 에서 버려지는 토큰의 비율을 재라.
- 문제 3.9 (탐구) CSR 의 열 번호를 정렬해 두면 $x$ 읽기의 라인 수가 줄어드는가. 정렬된 열 번호에서 인접 원소가 같은 라인에 들 확률을 밀도의 함수로 구하고, 문턱이 어디로 움직이는지 논하라.
- 문제 3.10 (탐구) 2:4 를 일반화한 $n$:$m$ 규칙에서 인덱스 비트와 밀도와 정확도 손실의 관계를 세우고, 어느 $(n, m)$ 이 이 기계와 전용 장치 각각에서 유리한지 논하라.

## 더 읽을 것

- Accelerating Sparse Deep Neural Networks (2021). 2:4 규칙을 읽는 행렬 곱 장치의 설계와 가지치기 절차. 3.2 절의 판정에 붙은 장치라는 조건의 출처다. (3.2절)
- QLoRA: Efficient Finetuning of Quantized LLMs (2023). 블록 64 의 4비트 양자화와 이중 양자화, 그리고 정규분포에 맞춘 조회표 NF4. 3.3 절의 정의가 실제 모델에서 어떻게 쓰이는지 보인다. (3.3절)
- GPTQ: Accurate Post-Training Quantization for Generative Pre-trained Transformers (2023). 반올림 순서를 바꿔 오차를 보상하는 사후 양자화. 정리 3.2 의 오차를 어떻게 더 줄이는지의 한 답이다. (3.3절)
- Switch Transformers: Scaling to Trillion Parameter Models with Simple and Efficient Sparsity (2022). 전문가 하나만 고르는 라우터와 용량 인자. 3.4 절의 알고리즘에 상한을 더한 것이 이 논문의 층이다. (3.4절)
