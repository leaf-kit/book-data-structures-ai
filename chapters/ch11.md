# 11장 계산 그래프

1962년의 논문 하나는 3만 개 활동의 순서를 한 시간 안에 정하는 방법을 제안했다.

## 절

- **11.1** 그래프의 세 표현. 정적인 그래프에서 CSR 이 메모리 5 분의 1, 전체 훑기 이백 배
- **11.2** 위상 정렬 둘과 역방향 미분. 역순 한 번이 모든 입력의 기울기이고, 팬아웃에서 합이다
- **11.3** 연산자 융합. 사슬을 노드 하나로. 싼 사슬에서 5.2 배, 비싼 사슬에서 1.3 배

## 연습문제

- 문제 11.1 (기초) 노드 $10^5$, 간선 $10^6$ 의 그래프를 4 바이트 정수의 CSR 로 두면 몇 MB 인가. 앞의 정의 로 구하고, 노드마다 포인터 8 바이트와 정수 배열의 인접 리스트와 견줘라.
- 문제 11.2 (기초) 노드 $n$, 간선 $m$ 의 DAG 에서 Kahn 의 알고리즘이 큐에 넣는 횟수와 차수 배열을 쓰는 횟수를 앞의 정의 로 적어라.
- 문제 11.3 (기초) $y = x (x) + x$ 의 계산 그래프를 그리고, 앞의 정의 대로 역방향을 손으로 밟아 $x = 0.5$ 에서 $ y / x$ 를 구하라. $x$ 에 몇 번 더해지는가.
- 문제 11.4 (기초) float32 원소 $10^8$ 개의 원소별 사슬 여덟 개를 하나씩 하면 이동량이 얼마이고 융합하면 얼마인가. 앞의 정의 로 구하고, 대역폭 800 GB/s 의 가속기에서 각각 몇 밀리초인가.
- 문제 11.5 (응용) `dsai.graph.CSRGraph` 에 간선을 더하는 `add_edges` 를 두 방식으로 구현하라. 열 배열을 다시 짜는 것과, 새 간선을 따로 모아 두었다가 일정 수가 쌓이면 합치는 것. 간선 만 개를 백 개씩 더할 때 시간을 견줘라.
- 문제 11.6 (응용) `dsai.topo.topo_dfs` 의 스택 항목을 튜플 대신 배열 둘 (노드, 다음 이웃 번호) 로 바꾸고 실험 11.2 의 시간이 얼마나 주는지 재라.
- 문제 11.7 (응용) `dsai.topo.ScalarGraph` 에 나눗셈과 exp 를 더하고, 유한 차분 검산이 통과하는지 확인하라. 팬아웃이 셋인 노드를 만들어 기울기가 세 번 더해지는지 시험으로 보여라.
- 문제 11.8 (응용) `dsai.fusion.fusable_chains` 를 축소 연산이 사슬의 끝에 올 수 있게 넓혀라. 앞의 정의 의 첫 문장이다. 축소 뒤에 원소별이 오면 사슬이 끊기는지 시험하라.
- 문제 11.9 (탐구) 역방향 미분에서 값을 저장하지 않고 다시 계산하면 메모리와 연산이 어떻게 맞바뀌는지 앞의 정의 의 비용으로 논하라. 그래프를 $n$ 개의 구간으로 나눠 구간 경계만 저장하면 어떻게 되는가.
- 문제 11.10 (탐구) 위상 순서가 여럿일 때 중간 텐서의 최대 메모리가 순서에 따라 달라지는 그래프를 하나 만들고, 두 순서의 최대 메모리를 견줘라.

## 더 읽을 것

- Topological Sorting of Large Networks (1962). 위상 정렬의 원전. 다섯 쪽이고, 들어오는 것이 없는 노드부터 꺼내는 규칙이 그대로 있다. (11.2절)
- Depth-First Search and Linear Graph Algorithms (1972). 깊이 우선 탐색으로 강한 연결 성분을 선형에 찾는 논문. 명시적 스택의 위상 정렬과 사이클 검출이 여기서 나왔다. (11.2절)
- Automatic Differentiation in Machine Learning: a Survey (2018). 자동 미분 조사. 역방향 모드가 그래프의 두 번 훑기라는 정리와 역사가 있다. (11.2절)
- TVM: An Automated End-to-End Optimizing Compiler for Deep Learning (2018). 딥러닝 컴파일러. 연산을 네 종류로 나눈 융합 규칙이 11.3 절의 경계 명제와 대응한다. (11.3절)
