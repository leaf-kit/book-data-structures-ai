# 5장 스택과 큐, 테이프와 배치

1964년 두 쪽짜리 논문이 함수를 원시 연산의 열로 풀어 놓으면 미분을 기계가 구할 수 있다고 적었다.

## 절

- **5.1** 스택을 정의하고, 재귀가 깊이 천에서 멈추는 동안 명시적 스택이 백만까지 가는 것을 잰다
- **5.2** 테이프. 앞으로 적고 뒤로 읽는 스택이 입력 수와 무관하게 편미분 전부를 준다
- **5.3** 링 버퍼. 옮기기 없는 큐가 창 통계를 상수 시간에 갱신한다
- **5.4** 배칭 큐. 꺼내는 단위를 요청에서 걸음으로 내리면 지연이 19분의 1 이 된다

## 대표 실험

## 연습문제

- 문제 5.1 (기초) 프레임 400 바이트, 상한 1,000 인 언어에서 재귀가 쓰는 스택 메모리의 최대와, 같은 깊이를 원소 16 바이트의 명시적 스택으로 갈 때의 메모리를 구하라. 명시적 스택으로 깊이 천만을 가면 얼마인가.
- 문제 5.2 (기초) $a = 3$ 에서 $b = a a$, $c = b a$ 를 계산하는 테이프의 항목 둘을 적고, 역방향으로 $ a$ 를 구하라. $c = a^3$ 의 미분과 같은지 확인하라.
- 문제 5.3 (기초) 용량 4 의 링 버퍼에 1 부터 6 까지 넣은 뒤 pop 둘을 했을 때 배열, 머리, 개수와 논리 순서를 적어라.
- 문제 5.4 (기초) 길이 $(8, 8, 64, 256)$ 인 요청 넷의 정적 배치에서 명제 5.6 의 낭비 비율을 구하고, 같은 넷을 연속 배칭이 부하가 충분할 때 어떻게 처리하는지 걸음 수로 적어라.
- 문제 5.5 (응용) `dsai.stack.depth_iterative` 를 일반 트리 (자식 여럿) 에 대해 재귀 순서와 같은 방문 순서를 내도록 고쳐라. 자식을 넣는 순서를 어떻게 해야 하는가.
- 문제 5.6 (응용) `dsai.tape.Tape` 에 행렬 벡터 곱을 원시 연산으로 더하라. 국소 미분을 어떻게 적어야 하는가. 실험 5.2 를 그 연산으로 다시 재고 교차점이 어디로 움직이는지 보라.
- 문제 5.7 (응용) `dsai.ring.WindowMean` 처럼 창 분산을 상수 시간에 갱신하는 클래스를 써라. 제곱합 하나가 더 필요하다. 창 최대값은 왜 같은 방법으로 안 되는지 적어라.
- 문제 5.8 (응용) `dsai.batching.simulate_continuous` 에 대기 큐를 도착 순서가 아니라 짧은 요청 먼저로 바꾸는 선택지를 더하고, 실험 5.4 에서 평균 지연과 p95 가 어떻게 바뀌는지 재라.
- 문제 5.9 (탐구) 테이프의 일부를 지우고 뒤로 올 때 다시 계산하면 메모리가 준다. 층 $L$ 개 중 $ L$ 개만 남기는 방법의 메모리와 추가 시간을 세우고, 명제 5.5 와 견줘라.
- 문제 5.10 (탐구) 연속 배칭에서 긴 요청이 계속 자리를 차지하면 짧은 요청의 대기가 는다. 자리를 잠시 내주는 선점을 넣을 때 KV 캐시를 어디에 두어야 하는지, 2장의 구조로 논하라.

## 더 읽을 것

- A Simple Automatic Derivative Evaluation Program (1964). 자동 미분의 원전. 두 쪽이다. 함수를 원시 연산의 열로 푸는 생각이 여기서 시작됐다. (5.2절)
- Automatic Differentiation in Machine Learning: a Survey (2018). 자동 미분 조사. 전진과 역방향의 비용, 테이프와 그래프의 차이, 프레임워크들의 분류가 있다. 정리 5.2 의 원전이다. (5.2절)
- Orca: A Distributed Serving System for Transformer-Based Generative Models (2022). 반복 단위 스케줄링의 원전. 5.4 절의 연속 배칭이 이 논문의 제안이고, 정적 배칭의 낭비 그림이 3장에 있다. (5.4절)
- Efficient Memory Management for Large Language Model Serving with PagedAttention (2023). 연속 배칭과 블록 테이블을 합친 서버. 5.4 절이 2장을 왜 필요로 하는지가 이 논문의 주장이다. (5.4절)
