# 15장 어텐션을 자료 구조로 읽기

2017년의 논문은 어텐션을 질의, 키, 값의 세 행렬로 적었다.

## 절

- **15.1** 어텐션은 소프트 연관 배열이다. 조회가 키 수에 선형이고, 상위 $k$ 근사의 오차는 버린 질량이다
- **15.2** 타일링과 온라인 소프트맥스. 점수 행렬 1 GB 가 4 MB 로, 시간은 8 퍼센트
- **15.3** KV 캐시 축출. 예산 256 에서 LRU 101 퍼센트, 헤비 히터 0.84 퍼센트
- **15.4** 고정 크기 상태. KV 캐시 34 GB 대 상태 16.8 MB, 스캔은 병렬 기계의 알고리즘

## 연습문제

- 문제 15.1 (기초) 길이 32,768, 차원 128, 헤드 32 의 점수 행렬이 float16 으로 몇 GB 인가. 앞의 정의 으로 셈하고, 타일 128 의 블록 점수는 몇 KB 인지 적어라.
- 문제 15.2 (기초) 길이 8,192, 차원 128 에서 점수 행렬 어텐션과 타일 어텐션의 이동량을 앞의 정의 로 구하고 배수를 적어라. 연산 밀도가 몇 배 오르는가.
- 문제 15.3 (기초) 예산 $B$, 보호 $r$ 의 헤비 히터 캐시에서 어느 토큰이 남는지 앞의 정의 으로 적어라. 오래됐지만 점수가 큰 토큰은 어느 정책에서 남고 어느 정책에서 나가는가.
- 문제 15.4 (기초) 층 32, 헤드 32, 차원 128 의 KV 캐시가 토큰 하나에 몇 KB 이고 길이 $10^5$ 에서 몇 GB 인가. 층 32, 채널 4,096, 상태 64 의 고정 상태는 몇 MB 인가. 앞의 정의 로 구하라.
- 문제 15.5 (응용) `dsai.attention.attention_tiled` 에 인과 마스크를 더하라. 질의 블록보다 뒤의 키 블록은 건너뛰고, 블록 안의 미래는 $-$ 로 막아라. 전부 유지한 인과 어텐션과 같은지 시험하고 건너뛴 블록 수를 세어라.
- 문제 15.6 (응용) 타일 크기를 8 에서 2,048 까지 바꾸며 `attention_tiled` 의 시간을 재라. 어느 크기에서 가장 빠르고, 작을 때와 클 때 무엇이 시간을 먹는가.
- 문제 15.7 (응용) `dsai.kvevict.decode_with_policy` 의 누적 점수를 지수 감쇠 합 $ + p$ 로 바꿔라. $ = 1$ 에서 원래와 같은지 시험하고, 참조 패턴이 도중에 바뀌는 열에서 오차를 견줘라.
- 문제 15.8 (응용) `dsai.ssm.run_scan` 을 블록 안은 닫힌 식, 블록 사이는 재귀로 바꿔라. 5장 누적합의 두 단계다. 재귀와 같은 출력인지 시험하고 블록 크기에 따른 시간을 재라.
- 문제 15.9 (탐구) 앞의 정의 를 근거로, 어텐션과 선형 재귀를 층마다 섞은 모델에서 어느 층에 어느 쪽을 두어야 하는지 논하라. 되찾기가 필요한 층과 요약으로 충분한 층을 어떻게 가리는가.
- 문제 15.10 (탐구) 연관 배열의 읽기와 어텐션의 읽기가 어디서 갈라지는지 앞의 정의 으로 적고, 12장의 근접 탐색과 15.3 절의 축출이 같은 명제의 두 얼굴인 이유를 논하라.

## 더 읽을 것

- Attention Is All You Need (2017). 어텐션의 원전. 질의, 키, 값의 표기와 $ d$ 의 이유가 있다. 연관 배열로 읽는 출발점이다. (15.1절)
- Online Normalizer Calculation for Softmax (2018). 온라인 정규화. 최댓값과 합을 한 번 훑기로 얻는 갱신이 정리 그대로 있다. (15.2절)
- FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness (2022). FlashAttention. 온라인 소프트맥스로 점수 행렬을 느린 메모리에 안 쓰는 타일 어텐션. 역방향의 재계산도 여기 있다. (15.2절)
- H2O: Heavy-Hitter Oracle for Efficient Generative Inference of Large Language Models (2023). 헤비 히터 오라클. 누적 어텐션 점수로 캐시를 예산 안에 두는 정책과 그 처리량. (15.3절)
- Efficient Streaming Language Models with Attention Sinks (2024). 어텐션 싱크. 첫 토큰 몇 개와 최근 창만 남기는 스트리밍 캐시. 15.3 절의 두 집합에서 헤비 히터를 고정한 경우다. (15.3절)
- Mamba: Linear-Time Sequence Modeling with Selective State Spaces (2023). 선택적 상태 공간. 고정 상태의 재귀를 입력에 따라 바꾸고, 스캔을 빠른 메모리 안에서 돌린다. (15.4절)

정의, 증명, 실험의 분석은 책에 있다.
