# 10장 힙, 선택, 표본 추출

1964년의 두 쪽짜리 알고리즘 하나는 배열 하나를 트리로 읽고 최대만 맨 위에 두는 것으로 정렬을 만들었다.

## 절

- **10.1** 이진 힙과 상위 $k$ 개. 정렬, 힙, 선택의 세 비용. 선택이 정렬보다 여덟 배
- **10.2** 빔 탐색. 단계마다 상위 $B$ 개 선택과 부모 배열. 빔 8 이 최선을 45 퍼센트
- **10.3** 누적합과 별칭표. 뽑기가 세 배 빠르고, top-p 는 남는 수가 정한다
- **10.4** 우선순위 스케줄러. 짧은 것 먼저의 최적성과 굶김, 나이 가중. 평균 다섯 배와 최대 네 배

## 연습문제

- 문제 10.1 (기초) 원소 $10^6$ 개에서 상위 100 개를 고를 때 정렬, 크기 100 힙, 선택의 비교 횟수 상한을 앞의 정의 로 구하라. 힙에서 실제 비교가 상한보다 훨씬 적은 이유를 적어라.
- 문제 10.2 (기초) 어휘 32,000, 빔 4, 길이 200 의 빔 탐색에서 점수 계산 수와 부모 배열의 크기를 앞의 정의 로 구하라. 열을 저장하면 몇 배인가.
- 문제 10.3 (기초) $p = (0.4, 0.3, 0.2, 0.1)$ 의 별칭표를 앞의 정의 의 증명대로 손으로 만들고, 자리마다 뽑힐 확률이 $p$ 와 같은지 불변식으로 확인하라.
- 문제 10.4 (기초) 길이 100 과 3,000 인 요청이 초당 1,000 토큰의 처리량에 번갈아 올 때, 나이 계수 100 에서 긴 요청의 최대 대기 상한을 앞의 정의 으로 구하라.
- 문제 10.5 (응용) `dsai.heap.MaxHeap` 에 배열에서 힙을 $O(n)$ 에 만드는 `heapify` 를 더하고, 넣기 $n$ 번과 시간을 견줘라. 앞의 정의 의 두 비용이 실측에서 어떻게 갈리는가.
- 문제 10.6 (응용) `dsai.beam.beam_search` 에 길이 정규화를 더하라. 점수를 길이로 나눠 견주면 어느 빔 폭에서 실험 10.2 의 결과가 어떻게 바뀌는지 재라.
- 문제 10.7 (응용) `dsai.sampling.top_p_mask_by_select` 의 시작 $k_0$ 를 이전 단계에서 남은 수로 두는 적응 규칙을 더하고, top-p 0.9 의 지프 분포에서 시간이 얼마나 주는지 재라.
- 문제 10.8 (응용) `dsai.scheduler.simulate` 의 나이 정책을 다시 매기지 않게 바꿔라. 키를 길이 $+ $ 도착 시각으로 두면 순서가 같음을 보이고, 실험 10.4 와 같은 대기가 나오는지 확인하라.
- 문제 10.9 (탐구) 빔 탐색의 후보 $B$ 개가 KV 캐시를 나누는 정도를 9.3절 의 라디스 트리로 적어라. 빔이 갈릴 때 트리에 무엇이 생기고, 5.4절 의 쓰기 시 복사와 어떻게 대응하는가.
- 문제 10.10 (탐구) 요청 길이를 모를 때 입력 길이로 추정하는 짧은 것 먼저가 앞의 정의 에서 얼마나 멀어지는지 논하라. 추정이 무작위이면 도착 순서와 같아지는가.

## 더 읽을 것

- Algorithm 232: Heapsort (1964). 이진 힙과 힙 정렬의 원전. 두 쪽이고, 배열 위의 완전 이진 트리라는 배치가 여기서 나왔다. (10.1절)
- An Efficient Method for Generating Discrete Random Variables with General Distributions (1977). 별칭표의 원전. 네 쪽이고, 두 번의 메모리 참조로 뽑는다는 문장이 그대로 있다. (10.3절)
- A Linear Algorithm for Generating Random Numbers with a Given Distribution (1991). 별칭표를 선형 시간에 만드는 알고리즘. 이 장의 만들기가 이것이다. (10.3절)
- The Curious Case of Neural Text Degeneration (2020). 최대화 디코딩의 퇴화와 top-p 뽑기. 10.2 절과 10.3 절을 잇는 근거다. (10.2, 10.3절)
- Orca: A Distributed Serving System for Transformer-Based Generative Models (2022). 연속 배칭의 원전. 10.4 절이 그 큐에 우선순위를 넣는다. (10.4절)
