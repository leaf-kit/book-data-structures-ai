# 1장 배열에서 텐서로

NumPy 의 설계를 정리한 2020년 논문은 배열 객체 하나가 중력파 검출과 블랙홀 첫 영상의 계산을 받쳤다고 적었다.

## 절

- **1.1** 배열을 연속성 불변식으로 정의하고, 원소가 참조일 때 그 불변식이 값에 대해 깨지는 것을 잰다
- **1.2** 스트라이드를 정의에 넣어 전치와 자르기를 이동량 0 의 연산으로 만든다
- **1.3** 간격 접근의 이동량을 정리로 세우고, 블록 순회로 전치를 열 배 넘게 줄인다
- **1.4** 배치가 연산 밀도를 올리는 산수를 명제로 세우고, 브로드캐스팅을 정의한다

## 연습문제

- 문제 1.1 (기초) float64 행렬 $3 4$ 를 행 우선으로 놓았을 때의 스트라이드를 구하고, 원소 $(2, 1)$ 의 바이트 위치를 계산하라. 열 우선이면 어떻게 달라지는가.
- 문제 1.2 (기초) 파이썬 리스트에 실수 백만 개를 넣었을 때의 메모리를 포인터 8바이트와 실수 객체 24바이트로 계산하고, float32 값 배열과의 비를 구하라.
- 문제 1.3 (기초) float64 배열을 간격 4 로 백만 개 읽을 때의 이동량을 정리 1.3 으로 계산하라. 간격 8 이면 어떻게 되는가.
- 문제 1.4 (기초) $n = 262,144$, $d = 128$, $s = 4$ 일 때 명제 1.5 로 $B = 1, 16, 256$ 의 연산 밀도를 계산하고, 능선점 8 을 넘는 최소 $B$ 를 구하라.
- 문제 1.5 (응용) 3차원 텐서 $(2, 3, 4)$ 의 첫 축과 셋째 축을 바꾼 뷰의 스트라이드를 `dsai.tensor.View` 로 구현하고, `np.swapaxes` 의 스트라이드와 같은지 확인하라.
- 문제 1.6 (응용) 실험 1.3 의 각 간격에 대해 정리 1.3 이 예측한 원소당 라인 수를 `dsai.tensor.lines_for_traversal` 로 구하고, 실측 원소당 시간과 한 표에 놓아라. 어디서부터 갈리는가.
- 문제 1.7 (응용) `dsai.tiling.tile_bytes` 로 L2 256KB 와 L3 8MB 각각에 드는 가장 큰 2의 거듭제곱 블록을 구하고, 실험 1.2 의 블록 64 와 1024 결과와 대조하라.
- 문제 1.8 (응용) `dsai.batch.intensity_batched` 로 능선점을 넘는 최소 배치 크기를 구하는 함수를 쓰고, 실험 1.5 에서 처리량이 오르기를 멈춘 자리와 비교하라.
- 문제 1.9 (탐구) 같은 행렬을 열 우선으로 저장하면 어떤 작업량에서 이기는가. 열 하나를 통째로 읽는 연산과 행 하나를 통째로 읽는 연산의 빈도로 답을 정리하라.
- 문제 1.10 (탐구) 실험 1.3 에서 간격 16 을 넘은 뒤에도 원소당 시간이 오르는 이유를 선인출과 주소 변환으로 가설을 세우고, 두 가설을 가르는 실험을 설계하라.

## 더 읽을 것

- Array Programming with NumPy (2020). NumPy 배열 객체의 설계. 타입, 스트라이드, 브로드캐스팅이 한 그림에 있다. 이 장 전체의 원전이다. (1.1, 1.2, 1.4절)
- What Every Programmer Should Know About Memory (2007). 캐시와 주기억의 동작을 백 쪽에 걸쳐 실측으로 보인 문서. 실험 1.3 이 왜 16 을 넘어서도 오르는지 여기에 답이 있다. (1.3절)
- Cache-Oblivious Algorithms (1999). 블록 크기를 모르고도 최적인 재귀 분할. 이 장이 명시적 블록을 택한 것과 견줘 읽는다. (1.3절)
- Orca: A Distributed Serving System for Transformer-Based Generative Models (2022). 배치를 요청 단위에서 토큰 반복 단위로 바꾼 논문. 명제 1.5 가 서버 설계로 자라는 자리다. (1.4절)
