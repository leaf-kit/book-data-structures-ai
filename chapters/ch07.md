# 7장 확률적 자료 구조

1970년의 두 쪽짜리 논문 하나는 하이픈 넣기 사전을 디스크에서 안 읽으려고 단어를 저장하지 않는 집합을 만들었다.

## 절

- **7.1** 블룸 필터. 거짓 양성률 정리와 최적 해시 수를 세우고, 키 백만 개에 1.2 MB 로 오답 1 퍼센트를 잰다
- **7.2** 카운트 민 스케치. 오차 상한 정리를 증명하고, 1 MB 로 천만 개 스트림의 상위 100 개를 찾는다. 하이퍼로그로그도 함께
- **7.3** MinHash 와 띠 나누기. 일치 확률이 자카드임을 증명하고 S 곡선을 실측한다
- **7.4** 세 구조를 이어 학습 데이터 중복 제거 파이프라인을 세우고 잰다

## 연습문제

- 문제 7.1 (기초) 키 천만 개를 오답률 0.1 퍼센트로 담는 블룸 필터의 비트 수와 해시 수를 앞의 정의 로 구하라. 같은 키를 8 바이트씩 개방 주소 표에 적재율 0.7 로 담을 때와 메모리를 견줘라.
- 문제 7.2 (기초) 스트림 십억 개에서 빈도가 전체의 0.01 퍼센트 이상인 키를 확률 99.9 퍼센트로 두 배 안에서 세려면 앞의 정의 로 폭과 깊이를 구하라. 표는 몇 MB 인가.
- 문제 7.3 (기초) 띠 20 줄 5 의 후보 확률을 앞의 정의 로 자카드 0.5, 0.7, 0.9 에서 구하라. 문턱 $(1/b)^1/r$ 은 얼마인가.
- 문제 7.4 (기초) 문서 십억 개, 서명 128 개의 파이프라인에서 앞의 정의 의 서명 메모리와 블룸 필터 메모리를 구하라. 조각 집합을 두면 문서당 4 KB 로 얼마가 더 드는가.
- 문제 7.5 (응용) `dsai.bloom.BloomFilter` 의 `bool` 배열을 `uint8` 의 비트 여덟 개로 접어 메모리를 여덟 배 줄이고, 실험 7.1 의 오답률이 같은지 확인하라.
- 문제 7.6 (응용) `dsai.bloom.BloomFilter` 를 앞의 정의 의 블록 블룸 필터로 바꿔라. 블록 512 비트에 자리 $k$ 개를 모으고, 키당 16 비트에서 오답률이 얼마나 오르는지 재라.
- 문제 7.7 (응용) `dsai.sketch.CountMinSketch` 에 보수적 갱신을 더하라. 더할 때 줄 전부를 올리지 않고 최소인 줄만 올린다. 실험 7.2 의 과대 추정이 얼마나 주는지 재라.
- 문제 7.8 (응용) `dsai.dedup.DedupPipeline` 의 확인 단계를 조각 집합 대신 서명 비교로 바꾸고, 실험 7.4 에서 걸러 낸 근사 중복 수가 어떻게 바뀌는지 재라.
- 문제 7.9 (탐구) 앞의 정의 의 배치 중복 제거에서 후보 쌍의 연결 성분을 찾는 데 해시 테이블 대신 정렬만으로 되는지 논하라. 안 되면 무엇이 더 필요한가.
- 문제 7.10 (탐구) 블룸 필터에서 키를 빼려면 비트를 4 비트 계수기로 바꾼다. 계수기가 넘칠 확률을 앞의 정의 의 방법으로 어림하고, 키 백만 개에서 넘치는 자리가 몇 개인지 추정하라.

## 더 읽을 것

- Space/Time Trade-offs in Hash Coding with Allowable Errors (1970). 블룸 필터의 원전. 두 쪽이고, 오답률의 식과 디스크를 안 가는 예가 다 있다. (7.1절)
- An Improved Data Stream Summary: The Count-Min Sketch and its Applications (2005). 카운트 민 스케치의 원전. 오차 정리의 증명과 내적, 범위 물음으로의 확장이 있다. (7.2절)
- HyperLogLog: The Analysis of a Near-Optimal Cardinality Estimation Algorithm (2007). 하이퍼로그로그의 원전. 상수 $_m$ 과 상대 오차 $1.04/m$ 의 유도가 있다. (7.2절)
- On the Resemblance and Containment of Documents (1997). MinHash 의 원전. 일치 확률 정리와 웹 문서 3천만 개의 실험이 있다. (7.3절)
- Approximate Nearest Neighbors: Towards Removing the Curse of Dimensionality (1998). 지역 민감 해싱의 틀을 세운 논문. 띠 나누기의 증폭이 여기서 일반화됐고, 12장의 디딤돌이다. (7.3절)
- Deduplicating Training Data Makes Language Models Better (2022). 학습 데이터 중복 제거가 모델에 미치는 영향. 접미사 배열과 MinHash 두 방법을 함께 썼다. (7.4절)

정의, 증명, 실험의 분석은 책에 있다.
